# 元气修复 · 微信小程序打卡应用

专为 **36岁、熬夜、嗜甜、缺运动、气血不足、爱叹气、脑疲劳** 的你设计的健康打卡小程序。

## 功能
- 📋 **今日打卡**：12项任务（抗糖/作息/运动/气血/健脑/护肤），点一下就打卡，带震动反馈 + 进度条
- 🍱 **食谱**：一周不重样，补气血（猪肝/红枣/桂圆/桑葚）+ 抗糖 + 健脑
- 🏃 **运动**：7天计划，每个动作标了组数×次数，含热身+拉伸
- 🌸 **气血专项**：腹式呼吸 / 按揉太冲穴（治叹气）/ 梳头 / 用脑50休10 / 23点睡 / 泡脚 —— 点开有详细做法
- 📊 **统计**：连续打卡天数🔥 + 近7天完成率柱状图 + 恢复节奏鼓励

## 目录结构
```
miniprogram/
├── app.js / app.json / app.wxss   # 全局逻辑/配置/样式
├── sitemap.json
├── 部署教程.md                      # ← 怎么导入手机看这里
└── pages/
    ├── today/    # 今日打卡（主页面）
    ├── recipe/   # 食谱
    ├── sport/    # 运动
    ├── qiqi/     # 气血专项
    └── stats/    # 统计
```

## 快速开始
1. 下载安装「微信开发者工具」：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开工具 → 导入项目 → 目录选本文件夹 → AppID 选「测试号」
3. 点「预览」→ 手机微信扫码 → 完成！

详细步骤见 **部署教程.md**

## 数据说明
- 打卡记录存在**本机**（wx.setStorageSync），无需联网
- 卸载微信或清理缓存会丢失，建议里程碑截图

## 技术细节（供修改）
- 无后端、无第三方依赖，纯原生微信小程序
- 任务定义在 `pages/today/today.js` 的 `TASKS`
- 食谱在 `pages/recipe/recipe.js` 的 `RECIPES`
- 运动在 `pages/sport/sport.js` 的 `SPORTS`
- 气血专项在 `pages/qiqi/qiqi.js` 的 `ITEMS`
- 主题色在 `app.wxss` 顶部 CSS 变量
